# i18n Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap runtime i18n with `zh-CN` / `en-US`, Ant Design locale sync, a Sidebar language switcher, and symmetry tests for translation keys.

**Architecture:** `react-i18next` loads JSON namespaces from `src/i18n/resources/`. `use-locale.ts` mirrors `use-theme.ts` (`system | zh-CN | en-US`). `App.tsx` wraps the tree with `I18nextProvider` and antd `ConfigProvider locale`.

**Tech Stack:** i18next, react-i18next, React 19, antd 6, Vite.

**Spec:** `docs/superpowers/specs/2026-05-28-i18n-design.md`

---

### Task 1: Dependencies & i18n Core

**Files:**
- Modify: `package.json`
- Create: `src/i18n/index.ts`
- Create: `src/i18n/antdLocale.ts`
- Create: `src/hooks/use-locale.ts`

- [ ] Install `i18next` and `react-i18next`.
- [ ] Create `use-locale.ts` with `system | zh-CN | en-US`, resolved locale from `navigator.language`.
- [ ] Initialize i18next with namespaces `common`, `sidebar`; `fallbackLng: 'zh-CN'`.
- [ ] Export `syncI18nLocale(resolvedLocale)` and `getAntdLocale(resolvedLocale)`.

### Task 2: Resource Files

**Files:**
- Create: `src/i18n/resources/zh-CN/common.json`
- Create: `src/i18n/resources/zh-CN/sidebar.json`
- Create: `src/i18n/resources/en-US/common.json`
- Create: `src/i18n/resources/en-US/sidebar.json`

- [ ] Seed `common` keys: locale labels, theme labels (for future), generic actions.
- [ ] Seed `sidebar` keys: workspace title, nav labels used in Phase 0 (`群聊空间`, `工作区`, `开发任务`, `资源`, `资源库`).

### Task 3: App Integration

**Files:**
- Modify: `src/App.tsx`

- [ ] Import `I18nextProvider` and wire `useLocale` + `syncI18nLocale` on change.
- [ ] Wrap with antd `ConfigProvider locale={getAntdLocale(resolvedLocale)}` outside `@lobehub/ui` provider.
- [ ] Set `document.documentElement.lang` on locale change.

### Task 4: Sidebar Language Switcher

**Files:**
- Modify: `src/pages/chat/components/Sidebar.tsx`

- [ ] Add Segmented locale switcher below theme bar (expanded) or icon row (collapsed).
- [ ] Replace Sidebar shell strings with `useTranslation('sidebar')`.
- [ ] Use `useTranslation('common')` for locale option labels.

### Task 5: Symmetry Test & Verification

**Files:**
- Create: `src/i18n/resources.test.mjs`
- Modify: `package.json`

- [ ] Test that every key in `zh-CN` exists in `en-US` for each namespace (recursive JSON walk).
- [ ] Add `test:i18n` script.
- [ ] Run `npm run test:i18n`, `npm run build`.

**Done when:** User can switch 跟随系统 / 简体中文 / English; Sidebar labels update; antd locale follows; test passes.
